[ 무엇인가 ]
DuckCDM 은 서울대병원 OMOP CDM(약 400만 명) 위에서 OHDSI ATLAS 3.0 을 바로 쓰게 해 주는 연구용 앱입니다. 코호트 정의·생성, 포함 기준별 환자 수, 개념(어휘) 검색과 개념집합, 데이터 소스 보고서(인구분포·진단·약물·검사 트리맵)를 제공합니다.

[ 접근 ]
· DRB(데이터심의위원회) 승인을 받은 연구자만 사용할 수 있습니다. 승인 후 사번이 등록되어야 열립니다.
· 개인 식별번호는 포함되지 않으며, 결과는 집계 수준으로 확인합니다.

[ 특징 ]
· OHDSI 표준 도구(SqlRender·Circe·Achilles)를 파이썬으로 옮겨 DuckDB 에서 실행 — Java 원본과 출력이 같음을 검증했습니다.
· OHDSI PhenotypeLibrary 의 코호트 정의 JSON 을 그대로 불러와 생성할 수 있습니다.
· 오픈소스: github.com/vitaldb/duckcdm (Apache 2.0)
